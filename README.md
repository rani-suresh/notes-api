# Notes API

A beginner FastAPI backend project with CRUD operations.

## Features

- Get all notes
- Get single note
- Create notes
- Update notes
- Delete notes
- Pydantic validation

## Tech Stack

- Python
- FastAPI
- Pydantic

## Run Project

Activate virtual environment:

```bash
venv\Scripts\activate
```

Run server:

```bash
uvicorn main:app --reload
```

Open Swagger Docs:

```txt
http://127.0.0.1:8000/docs
```
